# cafe and restaurant guide 

Create a premium, modern, stylish and visually stunning single-page café website.

CAFÉ DETAILS:
- Café name: [YOUR CAFÉ NAME]
- Location: [CITY / AREA / FULL ADDRESS]
- Specialty: [SPECIALTY COFFEE / BRUNCH / DESSERTS / ITALIAN / etc.]
- Vibe: Cozy, aesthetic, premium, youthful, Instagram-worthy
- Target audience: Young people, couples, friends, remote workers, food lovers
- Primary action: Book a table on WhatsApp / Call now / View menu
- Contact number: [PHONE NUMBER]
- WhatsApp number: [WHATSAPP NUMBER]
- Instagram: [INSTAGRAM LINK]
- Google Maps link: [MAPS LINK]
- Opening hours: [TIMINGS]

DESIGN STYLE:
Make it look like a high-end international café brand website—not a basic template.

Use:
- Warm coffee, cream, caramel, chocolate brown, soft beige and subtle gold colors
- Large cinematic food and café photography
- Bold modern typography: elegant serif headings + clean sans-serif body text
- Generous white space, premium spacing and smooth section transitions
- Rounded corners, soft shadows, glassmorphism effects and subtle grain texture
- Dark espresso-colored sections mixed with light cream sections
- Smooth scroll animations, fade-ins, image parallax and hover effects
- Fully mobile-first responsive design
- Fast loading, clean code and SEO-friendly structure

WEBSITE SECTIONS:

1. STICKY NAVBAR
- Café logo on the left
- Links: Home, About, Menu, Gallery, Reviews, Visit Us
- Prominent “Book a Table” button
- On mobile: hamburger menu with smooth slide-in navigation
- Navbar becomes blurred/frosted when user scrolls

2. HERO SECTION
- Full-screen background image or video of coffee, café interior, latte art or food
- Dark cinematic overlay for readable text
- Big headline:
  “Where Every Cup Feels Like Home”
- Subheadline:
  “Specialty coffee, fresh food and unforgettable vibes in [CITY].”
- Two buttons:
  - “Explore Menu”
  - “Book a Table”
- Small trust stats:
  - 4.8★ Google rating
  - Freshly brewed daily
  - Cozy ambience
- Add a subtle animated coffee-steam or floating coffee-bean effect

3. ABOUT / OUR STORY
- Short emotional brand story
- Highlight what makes the café unique
- Use 2–3 feature cards:
  - Specialty Coffee
  - Fresh Food
  - Aesthetic Ambience
- Include one large café photo with a small floating badge:
  “Since [YEAR]” or “Brewing Happiness Daily”

4. SIGNATURE MENU
- Create a stylish filterable menu
- Categories: Coffee, Food, Desserts, Beverages, Specials
- Each item should have:
  - Photo
  - Item name
  - Short appetizing description
  - Price
  - Optional “Bestseller” or “Chef’s Special” badge
- Add at least 8–12 sample items with placeholder prices
- Make menu cards interactive on hover
- Add a button: “View Full Menu” or “Order on WhatsApp”

5. GALLERY
- Create a modern masonry-style photo gallery
- Mix café interior, coffee close-ups, food, desserts, people enjoying and exterior shots
- Add hover zoom effect
- Use placeholder images initially; I will replace them with real café photos

6. WHY VISIT US
- Add 4 strong reasons:
  - Premium coffee
  - Freshly prepared food
  - Instagram-worthy interiors
  - Perfect for work, dates and hangouts
- Use icons, minimal animation and premium card design

7. CUSTOMER REVIEWS
- Add 3–6 stylish testimonial cards
- Include star ratings, review text, customer name and source such as Google Review
- Add a large highlighted review or rating badge:
  “4.8★ Rated by 500+ happy customers”
- Keep placeholders that I can replace with real reviews

8. EVENTS / OFFERS SECTION
- Add a section for:
  - Weekend brunch
  - Live music
  - Coffee workshops
  - Birthday celebrations
  - Seasonal offers
- Make it visually exciting with bold typography and a call-to-action

9. VISIT US / LOCATION
- Show café address, timings, phone number and WhatsApp button
- Add a clean embedded Google Map
- Add directions button
- Add “Book a Table” CTA

10. FOOTER
- Café logo
- Short brand line
- Quick links
- Contact details
- Social media icons: Instagram, Facebook, WhatsApp
- Copyright line

FUNCTIONALITY:
- Smooth scrolling navigation
- Mobile hamburger menu
- Menu category filtering
- Scroll reveal animations
- Hover effects on cards and images
- WhatsApp booking button with pre-filled message:
  “Hi! I would like to book a table at [CAFÉ NAME].”
- Click-to-call phone button
- Google Maps embed
- SEO meta title and description
- Accessible buttons and readable contrast

CONTENT INSTRUCTIONS:
- Write original, premium, warm and appetizing café copy
- Do not use generic robotic text
- Keep headlines short, bold and emotional
- Make the website feel like a lifestyle brand, not just a food business
- Use placeholder text only where my real details are missing
- Clearly mark all areas where I need to add photos, menu items, address and contact details

FINAL OUTPUT:
Give me a complete, production-ready website in one single HTML file with embedded CSS and JavaScript.
Make it extremely polished, creative, modern and premium—something that instantly makes the café look expensive, trendy and trustworthy.
